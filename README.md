

# 💬 Chat

A full-stack chat and online dating application built using JavaScript, Node.js, Express.js, and MySQL.

## ✨ Features

- 🔐 User authentication
- 👥 User-to-user messaging
- 🟢 Connection status (online/offline)
- 💬 Instant messaging
- 📎 File sharing
- 🔔 Unread messages
- ⏱️ Message timestamp
- ⚡ Real-time communication via Socket.IO

## 🛠️ Technologies

- JavaScript
- Node.js
- Express.js
- MySQL
- Socket.IO
- JWT
- Cookie


## 🚀 How to Run

### Application

```hash
git clone <YOUR_GIT_URL>
```
